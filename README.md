### 🛡️ SmartOmniSentinel
**Edge AI violence detection for CCTV**

A 7-stage real-time pipeline, not a notebook demo.

`YOLOv8 pose` → `34-dim keypoints` → `centroid tracking` → `16-frame GRU` → `5/8 vote smoothing` → `risk scoring` → `alert dispatch`

**F1 0.806** · precision 0.75 · recall 0.87
4 FPS · 30 s per-track alert cooldown
Async FastAPI + WebSocket dashboard (~150 ms refresh), JWT auth, SHA-256-hashed evidence, Gemini Vision scene descriptions
