## Featured Work

### 🛡️ SmartOmniSentinel — Edge AI CCTV Incident Detection
A 7-stage real-time pipeline for detecting violent incidents from surveillance video, built as a final-year applied ML project.

- **Pipeline:** YOLOv8n detection → ByteTrack tracking → pose estimation → GRU temporal classifier → risk scoring → alert dispatch
- **Result:** F1 = 0.734 on a binary violence-classification task, validated end-to-end
- **Scale:** ~211 files / ~14K lines of code, with real deployment debugging (Windows-specific constraints)
- Structured around three original methods, with research-paper and provisional-patent framing explored

🔗 [Repository](https://github.com/Omhari66/smart-omnisentinel-final/tree/main/smart-omnisentinel)

### 📚 AdaptIQ — RAG-Powered AI Study Assistant
An adaptive tutor that teaches, revises, and evaluates students using their own study material.

- **Modes:** Teacher, Revision, and Exam — each with distinct prompt architecture
- Focused on retrieval quality and mode-specific prompt engineering rather than a single generic chatbot flow

🔗 [Repository](https://github.com/Omhari66/adaptive-ai-tutor)
